Creator OS 개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-11

1. 이 앱은 무엇인가요

Creator OS는 채널 운영자 본인이 자신의 컴퓨터에서 실행하는 개인 영상 제작 도구로, 운영자가 소유한 YouTube 채널에 영상을 올리는 데 Google 계정 권한을 사용합니다.

Creator OS is a private video production tool that the channel owner runs on their own computer. It uses Google account access only to upload videos to YouTube channels the owner controls.

2. 사용하는 Google 데이터

  • youtube.upload: 운영자가 승인한 영상 파일과 제목·설명·공개 범위를 운영자 본인 채널에 업로드합니다.
  • youtube.readonly: 로그인한 채널의 ID·이름을 읽어 올바른 채널인지 확인하고, 업로드한 영상의 존재·공개 범위·처리 상태를 확인합니다.

youtube.upload: uploads owner-approved video files with their title, description and privacy setting to the owner's channel. youtube.readonly: reads the signed-in channel's ID and name to confirm it is the intended channel, and checks that an uploaded video exists, its privacy setting and processing status.

3. 저장과 공유

  • OAuth 토큰은 운영자 컴퓨터의 로컬 저장소에만 보관하며, 외부 서버로 전송하거나 다른 사람과 공유하지 않습니다.
  • 업로드 결과(영상 ID, 시각, 상태)는 운영자 컴퓨터의 작업 기록 파일에만 남습니다.
  • Google 사용자 데이터를 판매하거나 광고·제3자 제공 목적으로 사용하지 않습니다.
  • Creator OS의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

OAuth tokens are stored only on the owner's computer and are never sent to an external server or shared. Upload results (video ID, time, status) stay in local log files. Google user data is not sold or used for advertising or shared with third parties. Use of Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

4. 권한 철회와 삭제

Google 계정의 타사 앱 및 서비스에서 언제든 Creator OS의 접근 권한을 철회할 수 있습니다. 운영자는 로컬 토큰 파일을 삭제해 저장된 자격 증명을 지울 수 있습니다.

Access can be revoked at any time at Google Account → Third-party apps & services. Deleting the local token file removes the stored credential.
